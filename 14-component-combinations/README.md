# Component Combinations

**→ [The full matrix](MATRIX.md)** — all 153 component pairs, classified.

This is the part most system design material skips. Knowing what a cache is and what a queue is does
not tell you what happens when a queue backs up *behind* a cache-miss storm — and that interaction is
what real systems are made of.

Literal "all permutations" of 18 components would be 2¹⁸ = **262,144** subsets, almost all of them
meaningless (CDN + distributed lock). Pairs are the level where exhaustiveness is both achievable and
useful, so every one of the 153 is classified rather than a curated subset being presented as
coverage.

| Class | Meaning | Count |
|---|---|---|
| ● CORE | Worth a full page | 10 |
| ○ REAL | Genuinely shipped | 27 |
| · SITU | Situational, or commonly confused | 3 |
| ⚠ ANTI | A known mistake | 3 |
| — none | No meaningful interaction | 110 |

That 110 pairs are honestly marked *none* is the useful part. A matrix with no empty cells would mean
the classification was doing no work.

**Every CORE and REAL pair names a real system and a public source**, because a combination nobody
ships is a thought experiment, not a pattern.

`MATRIX.md` is generated by
[`scripts/gen_combination_matrix.py`](../scripts/gen_combination_matrix.py); CI fails if the
committed file drifts. Edit the generator, not the markdown.
